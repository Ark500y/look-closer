## Concept

**"The closer you look, the better the craft."**

**LOOK CLOSER** is a gallery exhibition portfolio engineered as an exponential camera journey ($s_i = 10^{z-i}$). Every level is $10\times$ deeper than the last, moving seamlessly from a deep-space red lens void down to an emissive $1:1$ pixel matrix at $1,000,000\times$ magnification.

At the exact center of each chapter sits a circular portal aperture ($10\%$ of viewport half-diagonal). Through it, you see the next chapter in miniature, which expands to fill the screen as you scroll.

---

## Chapters (z = 0 → 6)

1. **FIG. 01 / VOID**: 3-layer canvas starfield with radial velocity streaks and breathing ARK Red lens aperture.
2. **FIG. 02 / THE MAKER**: Sculptural monochrome portrait with red rim lighting and rotating orbital skill rings.
3. **FIG. 03 / THE ARC**: Regional dot-matrix map ($30^\circ\text{–}80^\circ\text{E}, 10^\circ\text{–}40^\circ\text{N}$) with animated geodesic transmission arcs from Sargodha to Dammam, Jeddah, and Dubai.
4. **FIG. 04 / AC TECHNICAL SERVICES**: Dubai commercial HVAC platform with emergency WhatsApp dispatch.
5. **FIG. 05 / BOOM TRUCK RENTAL**: Bilingual English/Arabic heavy machinery platform with native RTL engine (Dammam, KSA).
6. **FIG. 06 / ARK FAST FOODIES**: Restaurant branding, visual identity, and packaging poster gallery.
7. **FIG. 07 / THE NEXT PIXEL**: Resolves into an atomic $1:1$ red pixel terminus with instant WhatsApp project dispatch console.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation & Scrub Engine**: [GSAP](https://gsap.com/) (ScrollTrigger + ScrollToPlugin)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Typography**: [Google Fonts via next/font](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) (Instrument Serif, JetBrains Mono, Inter)
- **Cartography**: [d3-geo](https://d3js.org/d3-geo) + [topojson-client](https://github.com/topojson/topojson-client) + [world-atlas](https://github.com/topojson/world-atlas)
- **Image Processing**: [sharp](https://sharp.pixelplumbing.com/)

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Ark500y/look-closer.git

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.  
Accessible Fast Lane: [http://localhost:3000/lite](http://localhost:3000/lite)
